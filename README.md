# Event Invitation Page

This project is an event invitation page where users can RSVP for an event. The page includes event details, an RSVP form, and a thank you message upon form submission.

## Features

- **Hero Section**: A visually appealing hero section with a background image and event invitation message.
- **Event Details**: Information about the event including date, time, and location.
- **RSVP Form**: A form for users to submit their name, email, and number of guests.
- **Thank You Message**: A thank you message displayed upon successful form submission.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Setup Instructions

1. **Clone the repository**:
    ```sh
    git clone https://github.com/rehemathomas/event-invitation-page.git
    ```

2. **Navigate to the project directory**:
    ```sh
    cd event-invitation-page
    ```

3. **Open the project in your preferred code editor** (e.g., Visual Studio Code):
    ```sh
    code .
    ```

4. **Open the `index.html` file in your browser** to view the event invitation page.

## File Structure
event-invitation-page/ 
├── index.html 
├── style.css 
└── README.md

## Customization

- **Hero Section**: Update the background image and text in the `.hero` section in `index.html`.
- **Event Details**: Modify the event details in the `.event-info` section in `index.html`.
- **RSVP Form**: Customize the form fields and styles in the `.rsvp` section in `index.html` and `style.css`.
